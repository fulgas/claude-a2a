Claude Code plugin · Agent2Agent protocol

Let Claude talk to other agents, and let them talk to Claude.

Call any A2A agent from a Claude Code session, or serve the session as one. JSON-RPC with SSE streaming, HTTP+JSON and gRPC, on both sides.

/plugin marketplace add fulgas/claude-a2a
/plugin install a2a@claude-a2a
  • Client four tools: card, send, get_task, cancel_task
  • Server /a2a-serve: each incoming task runs as a subagent
  • Safe default loopback only until you set a token
